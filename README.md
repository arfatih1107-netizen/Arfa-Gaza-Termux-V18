## 🚀 Cara Instalasi Otomatis (1-Klik)

Gak perlu ribet buka nano dan copy-paste kode panjang! Cukup salin dan jalankan perintah otomatis di bawah ini di Termux kalian:

```bash
pkg update && pkg upgrade -y && pkg install neofetch curl -y && curl -o ~/.bashrc [https://raw.githubusercontent.com/arfatih1107-netizen/Arfa-Gaza-Termux-V18/main/indonesia_ch.sh](https://raw.githubusercontent.com/arfatih1107-netizen/Arfa-Gaza-Termux-V18/main/indonesia_ch.sh)
Setelah proses unduh selesai, langsung muat ulang Termux kalian dengan perintahsource ~/.bashrc
Fitur Utama
Pure Case Logic: 100% Anti-Pinguin nyasar, nomor yang dipilih pasti akurat mengeluarkan logo distro yang sesuai.
Dual Column Responsive: Menu 2 kolom vertikal yang pas, tidak meluber meskipun ukuran font Termux kalian besar.
